eskistyle guide · 1:1 with the collaboration mockup

Grounds

Surfaces separate by background step, not borders. paper is the page; surface is a panel; plate is hover/active; rail is the darkest.

Ink

Four text steps plus the inverse. Hierarchy is carried by weight and these steps, never by hue.

Lines (rare: field borders, the odd divider)

Member colours

The only hue in the product, and only inside a server (F12a): a member's name/avatar in chat, the members rail, contributor chips, canvas-comment authors, board assignees. Never on a profile or the public feed.

Type

Jost only, sentence case everywhere. Weights 400 / 600 / 700.
